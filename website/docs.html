powerPlus 사용 설명서

파워포인트 작업창에서 회사 자산을 검색해 클릭 한 번으로 슬라이드에 넣는 추가 기능입니다.
설치부터 관리자 화면까지 이 문서 한 장에 담았습니다.

Version 1.0.4 Updated 2026-09-20 Assets 3,734 Platform Windows · macOS

개요

powerPlus는 파워포인트 오른쪽에 열리는 작업창(task pane)입니다.
회사가 보유한 아이콘·사진·일러스트·다이어그램·로고와 지난 제안서 장표를 카테고리와 키워드로 찾아, 카드를 클릭하면 지금 작업 중인 슬라이드에 바로 삽입합니다.

자산과 애드인 본체는 모두 서버에서 불러오는 웹 방식입니다.
그래서 기능이 업데이트돼도 재설치가 필요 없고, 작업창을 닫았다 다시 열면 최신 화면이 뜹니다.

파워포인트 안에서 열린 powerPlus 작업창 — 실제 운영 화면입니다.

Heads up · Office 2016

Office 2016 이하는 내부 웹 엔진이 IE11이라 작업창이 백지로 뜹니다.
설치 마법사가 레지스트리로 Office 버전을 자동 감지해 미리 안내하며, 작업창 쪽에도 안내 페이지가 대신 표시됩니다.
사내는 Office Professional 2021을 쓰지만 신규 설치를 하지 않은 PC에는 2016이 남아 있을 수 있습니다.

설치하기

powerPlus_Setup.exe를 더블클릭하면 설치 마법사가 실행됩니다. 관리자 권한이 필요 없고 5단계로 1분 안에 끝납니다.

Step 1
시작

요구사항을 확인합니다.
좌측에 전체 5단계 진행 상태가 표시됩니다.

Step 2
라이선스 동의

사내 사용 한정, 자산의 외부 무단 배포 금지, 삽입·즐겨찾기 통계는 서비스 개선 목적으로만 수집. 동의 체크 후 다음 버튼이 활성화됩니다.

Step 3
설치 옵션

기본 경로 %LOCALAPPDATA%\powerPlus 그대로 두면 됩니다.
사용자 폴더라 관리자 권한이 필요 없습니다.

Step 4
설치 진행

파일 복사와 파워포인트 추가 기능 등록이 자동으로 진행됩니다.
수 초면 끝납니다.

Step 5
완료

“지금 PowerPoint 실행하기”를 체크한 채 완료를 누르면 파워포인트가 바로 열립니다.

Note · 업데이트

애드인 본체와 자산은 서버에서 불러오므로 로컬에는 등록 정보만 설치됩니다.
이후 기능이 업데이트돼도 재설치할 필요가 없습니다.
설치 파일은 리본 아이콘이나 매니페스트가 바뀔 때만 새로 받으면 됩니다.

작업창 열기

설치 후 파워포인트 상단 메뉴에서 다음 경로로 들어갑니다.
한 번 열어 두면 이후에는 파워포인트를 켤 때 자동으로 같이 뜹니다.

삽입→추가 기능→개발자 추가 기능→powerPlus

로그인 · 이메일 인증

비밀번호가 없는 이메일 인증코드(OTP) 방식입니다.

  1. 회사 이메일(아이디@solideos.com)을 입력하고 인증코드 받기를 누릅니다.
  2. 메일로 온 6자리 코드를 입력하면 로그인 완료.
  3. 로그인 상태는 유지됩니다.
    토큰이 만료될 때만 다시 인증하면 됩니다.
  • 회사 도메인 외 이메일은 사용할 수 없습니다.
  • 인증 메일이 안 보이면 스팸함·프로모션함을 확인하세요.
  • 인증코드는 10분간 유효하고, 재발송은 1분 간격으로 가능합니다.

Tip · 창을 넓히면 더 많이 보입니다

작업창 폭에 맞춰 그리드 열 수가 자동으로 늘어납니다(최대 7열). 작업창 경계를 드래그해 넓히면 한 화면에 더 많은 자산이 들어옵니다.

자산 탐색과 삽입

  • 삽입 — 카드를 클릭하면 현재 슬라이드에 바로 들어갑니다.
    이미지 자산은 이미지로, 장표 자산은 슬라이드 자체로 삽입됩니다.
  • 위치 지정 — 슬라이드에서 도형이나 개체를 먼저 선택해 두면 그 위치·크기에 맞춰 삽입됩니다.
  • 즐겨찾기 — 카드 우상단 북마크 버튼으로 등록·해제합니다.
    서버에 저장되므로 PC를 바꿔도 유지됩니다.
  • 화질 — 목록은 가벼운 썸네일로 표시하고, 삽입할 때는 원본 화질이 들어갑니다.

Heads up · 첫 삽입

설치 직후 슬라이드를 한 번도 클릭하지 않은 상태에서는 삽입 지점이 없어 실패할 수 있습니다.
슬라이드를 한 번 클릭해 커서를 둔 뒤 다시 시도하세요.
브라우저에서 애드인을 열었을 때도 삽입은 동작하지 않습니다.

카테고리와 주제

검색어 없이 카테고리 칩만 눌러도 그 카테고리 전체가 보입니다.
칩마다 등록 수가 함께 표시돼 어디에 자료가 많은지 한눈에 보입니다.

카테고리를 고르면 아래에 주제 칩이 나타납니다.
아이콘·사진·일러스트·다이어그램은 태그 빈도를 실측해 만든 주제로, 로고는 기관 이름 기준(정부·지자체·진흥원 등)으로, 장표는 페이지 종류(표지·목차·간지·본문·Q&A)로 나뉩니다.
결과가 0건인 주제는 아예 표시되지 않습니다.

일러스트 카테고리 — 인물·직장인, 회의·발표, 분석·차트 같은 장면 단위 주제로 나뉩니다.

로고 카테고리 — 정부 부처, 지자체, 공단·공사로 한 번 더 나눠 찾습니다.

검색

검색창에 키워드를 입력하고 Enter 또는 돋보기를 누릅니다.
국문·영문 태그와 자산명을 함께 찾습니다.

검색어를 고쳐서 찾습니다

사람은 자산에 붙은 이름을 모르고 검색합니다.
powerPlus는 자산 쪽 태그를 늘리는 대신 검색어 쪽을 고쳐 그 간극을 메웁니다.
고쳐서 찾은 경우 결과 바에 “‘코드’로 고쳐서 찾았어요”처럼 알려 줍니다.

실제 등록된 태그와 대조해 고치므로 자산이 늘어나도 그대로 동작합니다.
이미 정확한 검색어는 건드리지 않습니다.

알아 두면 좋은 것

  • 색상 검색 — “파란 아이콘”처럼 색을 섞어 칠 수 있습니다.
    자산마다 색상 태그가 자동으로 붙어 있습니다.
  • 카테고리 안에서 검색 — 카테고리를 고른 뒤 검색하면 그 안에서만 찾습니다.
  • 추천 검색어 — 입력하는 동안 실제 등록된 태그에서 후보를 보여 줍니다.
    없는 말은 만들어 주지 않습니다.
  • 결과가 없으면 — “‘키워드’ 자료 요청하기” 버튼이 나타나 콘텐츠 요청으로 바로 이어집니다.
  • 되돌아오기 — 검색 버튼이 ×로 바뀝니다.
    Esc를 눌러도 해제됩니다.

같은 스타일 세트

자산 카드에 마우스를 올리면 오른쪽 아래에 격자 버튼이 나타납니다.
누르면 같은 스타일로 함께 등록된 세트가 한 화면에 모이고, 그 자리에서 바로 삽입할 수 있습니다.
내가 누른 자산은 주황 테두리로 표시됩니다.

세트는 등록 배치(같은 소스·같은 파이프라인)와 색감·채도·밝기 실측 지문을 함께 봐서 묶습니다.
그래서 같은 날 들어온 자산이어도 파란 톤 플랫과 사실적인 컬러 인물은 서로 다른 세트로 갈립니다.

슬라이드 하나에 같은 톤의 자산을 여러 개 써야 할 때 가장 빠른 경로입니다.

장표 삽입

장표는 지난 제안서를 낱장으로 잘라 등록한 PPT 자산입니다.
주제 칩으로 표지 · 목차 · 간지 · 본문 · Q&A · 패키지를 골라 볼 수 있고, 카드 좌상단에 종류 뱃지가 표시됩니다.

유형클릭했을 때
패키지제안서 한 벌 전체가 현재 슬라이드 뒤에 삽입됩니다
단일표지·목차·간지·본문 등 1장만 삽입됩니다

삽입된 슬라이드는 글꼴·색·도형 등 원본 서식을 그대로 유지합니다.
내용만 고쳐 쓰면 됩니다.

즐겨찾기 · 최근

  • 즐겨찾기 탭 — 북마크한 자산만 모아 봅니다.
    자주 쓰는 표지나 아이콘을 등록해 두면 매번 검색할 필요가 없습니다.
  • 최근 탭 — 내가 최근에 삽입한 자산입니다.
    “지난번에 썼던 그 사진”을 다시 찾을 때 가장 빠릅니다.

두 목록 모두 서버에 저장되므로 다른 PC에서 로그인해도 그대로 유지됩니다.

웹 이미지

사내 라이브러리에 없는 이미지가 필요할 때, 작업창 안에서 외부 무료 이미지를 검색해 바로 삽입할 수 있습니다.

  • 검색 소스는 Openverse — 상업적 사용이 가능한 오픈 라이선스 이미지 위주입니다.
  • 결과 격자에서 클릭하면 원본이 슬라이드에 삽입됩니다.
  • 스크롤 끝까지 내리면 다음 페이지가 이어집니다.
  • 검색어는 영문 키워드가 결과가 더 풍부합니다 — technology, business, meeting 등.

콘텐츠 요청

필요한 자료가 라이브러리에 없으면 관리자에게 직접 요청할 수 있습니다.
검색 결과가 없을 때 뜨는 버튼이나 프로필 메뉴에서 열립니다.

항목설명
유형아이콘 / 사진 / 일러스트 / 다이어그램 / 장표 / 로고 — 관리자 카테고리와 연동
제목 · 키워드필수. 예: “친환경·ESG 관련 3D 아이콘”
상세 설명원하는 스타일·색감·용도를 자유롭게
참고 링크선택. 참고할 이미지나 사이트 주소

보낸 요청은 관리자 요청 관리 화면에 접수되고, 검토 후 라이브러리에 추가됩니다.

관리자 대시보드

관리자 주소로 접속해 관리자 계정으로 OTP 로그인합니다(애드인과 같은 방식). 좌측 내비게이션에서 현황 · 콘텐츠 관리 · 사용자 소통 그룹으로 이동합니다.

  • 인기 자산 / 즐겨찾기 TOP, 활발한 사용자 / 최근 삽입 내역
  • 인기 검색어 / 무결과 검색어 — 무엇을 찾았고, 무엇을 못 찾았는지

Tip · 무결과 검색어가 가장 중요한 화면입니다

결과가 0건이었던 검색어 목록은 실패 기록이 아니라 다음에 무엇을 채워야 하는지 사용자가 직접 알려 준 목록입니다.
콘텐츠 요청과 함께 보면 자산 보강 우선순위가 그대로 나옵니다.
이 목록대로 채운 결과 무결과율이 8월 18.2%(검색 1,685건)에서 9월 9.9%(검색 131건)로 내려갔습니다. 9월은 표본이 작아 아직 추세로 보기는 이릅니다.

자산 관리

자산의 조회·등록·수정·삭제를 담당합니다.
카테고리 필터, 태그 검색, 정렬(최신·이름·즐겨찾기·인기), 썸네일 크기 슬라이더, 페이지당 개수를 툴바에서 조절합니다.
카드를 클릭하면 우측에 상세 패널이 열립니다.

새 자산 등록

  • 이미지 자산(아이콘·사진·일러스트·다이어그램·로고) — PNG/JPG 업로드. 서버가 카테고리별 크기로 자동 리사이즈하고 썸네일을 만듭니다.
  • 장표 — .ppt / .pptx 업로드(필수) + 썸네일(선택). 유형은 패키지(전체 삽입) 또는 단일(표지·목차·간지·본문·Q&A·기타)을 고릅니다.
  • 태그 — 국문·영문으로 넉넉하게. 동의어·용도·색상까지 넣어야 검색 적중률이 올라갑니다.

Note · 대량 등록

수십~수백 개를 한 번에 올릴 때는 관리 화면 대신 드롭 폴더 파이프라인을 씁니다.
리사이즈 → 비전 태깅(국문 25·영문 25) → 색상 자동 태깅 → 서버 임포트가 한 줄기로 이어집니다.
자세한 절차는 저장소의 server/bin/ASSET-IMPORT.md 런북을 참고하세요.

공지 · 요청 관리

공지

사용자 애드인의 알림에 표시되는 공지를 관리합니다.
새 공지를 등록하면 즉시 전체 사용자에게 배지가 뜹니다.
지우지 않고 내리려면 상태를 비활성으로 바꾸면 됩니다.

요청

사용자가 보낸 콘텐츠 요청이 접수되는 곳입니다.
목록에 유형·제목·요청자·상태·등록일이 표시되고, 신규 → 완료 / 거절로 상태를 관리합니다.

증상원인과 해결

그래도 없으면 설치 파일을 다시 실행합니다.

1분 뒤 재발송할 수 있습니다.

설치 파일을 다시 실행하면 갱신됩니다.
