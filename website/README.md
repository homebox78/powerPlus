# powerPlus 소개 사이트

정적 HTML 5장. 서버 없이 `index.html` 을 브라우저로 열면 그대로 동작합니다.

## 폴더

| 경로 | 내용 |
|---|---|
| `index.html` | 홈 — 오로라 그라데이션 히어로, 핵심 메시지(축적·일관성) |
| `features.html` | 기능 — 자산 라이브러리 / 한국어 검색 / 장표 삽입 |
| `usecases.html` | 활용 사례 — 제안서·사내 보고·교육 자료 |
| `pricing.html` | 요금제 — Team·Business·Studio + 구축형 |
| `docs.html` | 문서 — 설치부터 관리자 화면까지 |
| `spoqa-400/500/700.woff2` | Spoqa Han Sans Neo 서브셋(629자, 3굵기 113KB) |
| `img/` | 아이콘 월 이미지 |
| `shots/` | 제품 스크린샷 |
| `_src/build.py` | 페이지 4장(홈·기능·활용·요금제) 생성기 — **여기가 원본** |
| `_src/polish.py` | 문장 끝 마침표 뒤 줄바꿈 삽입 |

`docs.html` 은 생성기를 거치지 않고 직접 작성한 문서입니다.

## 다시 빌드하기

```
cd _src
py build.py          # index / features / usecases / pricing 생성
py polish.py index.html features.html usecases.html pricing.html
```

`build.py` 는 페이지 사이 링크를 `{{HOME}}` `{{FEATURES}}` 같은 토큰으로 남깁니다.
로컬에서 쓰려면 그 토큰을 `index.html` `features.html` … 파일명으로 바꾸면 됩니다.

## 실제로 동작하는 것

정적 HTML 이지만 목업이 아니라 눌리는 대로 동작합니다. 스크립트는 페이지 안에 인라인으로 들어 있고,
자바스크립트가 꺼져 있어도 내용은 전부 읽힙니다.

| 기능 | 동작 | 위치 |
|---|---|---|
| 월 / 연 결제 탭 | 누르면 금액이 20% 할인가로 바뀜 (29,000 → 23,200 · 19,000 → 15,200) | 요금제 |
| FAQ 아코디언 | 질문을 누르면 펼침 · 스크립트가 없으면 전부 펼쳐진 상태 | 요금제 |
| 모바일 메뉴 | 1000px 아래에서 햄버거 → 메뉴 패널 (Esc · 바깥 클릭 · 링크 클릭 시 닫힘) | 전 페이지 |
| 맨 위로 | 420px 이상 내리면 우하단에 나타남 | 전 페이지 |
| 같은 페이지 앵커 | 부드럽게 이동하고 주소창에 해시가 남음 | 전 페이지 |
| 문서 사이드바 | 검색 필터 · 목차 자동 생성 · 현재 위치 표시 | 문서 |

`prefers-reduced-motion` 을 켠 환경에서는 부드러운 스크롤과 펼침 전환이 꺼집니다.

## 디자인 근거

수치는 눈대중이 아니라 참조 사이트의 실제 CSS 에서 뽑았습니다.

**구성·레이아웃 — aside.com**

| 항목 | 값 |
|---|---|
| 히어로 | 화면 16px 안쪽 라운드 카드(반지름 32px, overflow hidden) |
| 내비 | 홈은 카드 안(56px, 같이 스크롤) / 나머지는 상단 고정 흰 바 |
| 스크린샷 | 최대 1320px, 좌우 60px, `-128px` 로 당겨 카드가 아래를 잘라냄 |
| 세로 헤어라인 | 1240px — 안쪽 콘텐츠가 nextsaas 와 같은 1140px 이 되게 |
| 안쪽 여백 | 50px, 세로 110px |

**타이포 — greencar-gcar.co.kr + nextsaas**

| 요소 | 크기 | 굵기 | 색 | 행간 |
|---|---|---|---|---|
| 히어로 제목 | 68px (태블릿 50 / 모바일 34) | 500 | `#1A1A1C` | 1.10 |
| 섹션 제목 | 60px (태블릿 46 / 모바일 32) | 500 | `#1A1A1C` | 1.10 |
| 설명글 | 18px (모바일 16px) | 400 | `#55585E` | 1.60 |
| 자간 | 제목 −0.02em · 본문 −0.01em | | | |

글꼴은 **Spoqa Han Sans Neo** 서브셋(3굵기 113KB). 강조는 굵기가 아니라 **브랜드 색**으로 준다.

**섹션 구분 — i-bricks.co.kr**

섹션 사이를 실선 대신 **양 끝이 투명해지는 2px 그라데이션 라인**으로 나눈다.

```css
linear-gradient(90deg, rgba(255,255,255,0) 0%,
                       rgba(102,102,102,.2) 25%,
                       rgba(102,102,102,.2) 70%,
                       rgba(255,255,255,0) 100%)
```

**세련도 — nextsaas-wp.pixels71.com/insurance**

| 요소 | 값 |
|---|---|
| 콘텐츠 폭 | 1140px (헤어라인 프레임 1240px) |
| 섹션 라벨 | 틴트 pill — 14px/500 · radius full · padding 0 20px · 높이 33px |
| 버튼 | radius full · 일반 43px(0 20px, 14px) · 히어로 `.btn--lg` 54px(0 32px, 16px) |
| 카드 | radius **20px** · padding **32px** · 흰색 · 보더·그림자 없음 |
| 다크 패널(CTA) | `#1A1A1C` · radius **32px** · padding **72px 42px** + 모서리 오로라 글로우 |
| 섹션 배경 | 흰색 ↔ `#F4F5F8` 자동 교대 (`main > .band:nth-of-type(even)`) |
| 히어로 배경 | **CSS 메시 그라데이션** — radial-gradient 6겹, 이미지 0바이트 |

히어로 하늘은 사진을 쓰지 않는다. 레퍼런스처럼 파스텔 워시를 CSS 로 그려서
용량이 0이고 화면 크기와 무관하게 선명하며, 남의 이미지를 빌려 쓰지 않는다.

## 남은 확인거리

- 외부 폰트·이미지 의존이 없습니다. 인터넷 없이도 그대로 뜹니다.
- 활용 사례의 카드 3장은 파워포인트 창 전체 캡처라 좁은 폭에서 글씨가 작습니다.
  작업창만 잘라낸 캡처로 바꾸면 읽힙니다.
- 요금제 금액은 구조를 보여 주는 예시이며 확정 전입니다.
