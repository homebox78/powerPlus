powerPlus 자산 라이브러리 — 설치 안내 (Windows)
====================================================

[ 설치 방법 ]
1) 이 폴더의  설치.bat  를 더블클릭합니다.
   - "Windows의 PC 보호" 경고가 뜨면 → [추가 정보] → [실행] 클릭
2) PowerPoint 를 완전히 종료했다가 다시 실행합니다.
3) [홈] 리본 오른쪽에 "powerPlus → 자산 라이브러리" 버튼이 생깁니다.
4) 버튼을 누르면 오른쪽에 작업창이 열립니다.
5) 회사 이메일(@solideos.com)로 로그인 (인증코드가 메일로 발송됩니다).

[ 제거 방법 ]
   제거.bat  를 더블클릭한 뒤 PowerPoint 를 다시 시작합니다.

[ 필요 조건 ]
- Windows + PowerPoint (Microsoft 365 또는 2016 이상)
- 인터넷 연결 (자산 이미지는 회사 서버에서 불러옵니다)

[ 참고 ]
- 관리자 권한이 필요 없습니다 (사용자별 설치).
- Mac 사용자는 설치 방법이 다르니 관리자에게 문의하세요.
