# 장표(PPT) 등록 파이프라인 — 전체본 + 낱장 분기

완성된 발표 장표 하나를 **전체 패키지 1건 + 슬라이드별 낱장 N건**으로 등록한다.
낱장이 따로 등록돼야 "표지만", "로드맵만", "조직도만" 같은 검색이 걸린다.

## 흐름

```
data/_incoming/ppt/<파일>.pptx
  ① optimize.py   이미지 다운스케일 + 불투명 PNG→JPEG + 알파 PNG 조건부 양자화
  ② split.py      슬라이드 1장짜리 낱장으로 분할(zip 수술, 마스터 가지치기)
  ③ render.py     PowerPoint COM 으로 슬라이드 PNG 렌더(썸네일 겸 검수용)
  ④ dump.py       슬라이드별 텍스트 추출 → 키워드 작성 근거
  ⑤ sheet.py      번호 컨택트시트 → 눈으로 분류·키워드 확정
  ⑥ meta.py       이름 · slide_page · 키워드 정의(meta.sample.py 복사해 작성)
  ⑦ stage.py      _stage/ppt/{files,thumbs,manifest.json} 구성
  ⑧ tar → scp → server/bin/import-ppt.php (웹루트 임시 사본 + curl ?key=)
```

## 실행 예

```bash
PY="C:/Users/hbox7/AppData/Local/Python/pythoncore-3.14-64/python.exe"
cd <작업폴더>

# ① 최적화 (마지막 인자 = 이미지 최대 변, 1200 이면 대개 40MB 아래로 떨어진다)
"$PY" optimize.py "d:/powerPlus/data/_incoming/ppt/원본.pptx" full.pptx 1200

# ② 낱장 분할
"$PY" split.py full.pptx parts

# ③ 썸네일 렌더(전체) / 특정 장만 하려면 뒤에 번호 나열
"$PY" render.py full.pptx thumbs

# ④⑤ 텍스트·시트로 내용 파악
"$PY" dump.py && "$PY" sheet.py 1 16

# ⑥ meta.py 작성 후 ⑦ 스테이징
"$PY" stage.py
```

이후 `_stage/ppt` 를 tar 로 묶어 서버 `<webroot>/_stage/` 에 풀고,
`bin/import-ppt.php` 를 웹루트로 복사해 `curl 'localhost/powerPlus/<임시>.php?key=<import_key>'`.

## 규칙 · 함정

- **용량**: 서버 장표 상한 40MB. 이미지 최대 변 1200px 이면 233MB → 25MB 수준으로 떨어지고
  원본과 렌더 색차 0.1 미만(육안 구분 불가)이다. 값을 바꾸면 반드시 렌더를 대조할 것.
- ⚠️ **낱장이 전부 원본 크기로 나오면 마스터 가지치기가 안 된 것**이다. slideMaster 가
  전체 layout 을 참조하므로, 그 슬라이드가 쓰는 layout 만 남기지 않으면 미디어가 통째로 딸려온다.
  `split.py` 는 master 의 `sldLayoutIdLst` 와 master.rels 를 함께 잘라낸다.
- ⚠️ 낱장에는 notesMaster·handoutMaster·섹션 목록(`p14:sectionLst`)을 남기지 않는다.
  남기면 다른 제안서의 빈 섹션이 탐색창에 보인다.
- **분류**(`slide_page`): cover / toc / divider / content / qa / etc. 전체본은 `slide_kind: package`.
- **키워드**: 장표 안에 실제로 쓰인 말을 우선 넣는다(폭염·영향체인·G-클라우드처럼).
  거기에 ①용도(로드맵·조직도·구성도·간지) ②도메인(기후위기적응·웹지아이에스) ③표기 변형
  (Web-GIS → 웹지아이에스)을 더한다. 사업 공통 키워드는 `COMMON_KO/EN` 으로 전 낱장에 얹는다.
- 등록이 끝나면 **로컬 원본은 삭제**한다(서버가 라이브 라이브러리).

# 장표 안 아이콘·일러스트를 powerPlus 자산으로 교체

받은 pptx 의 그림을 라이브러리 자산으로 바꾼다. **위치·크기·레이아웃은 안 건드린다** —
슬라이드 XML 의 도형 좌표는 그대로 두고 `ppt/media/` 의 이미지 바이트만 갈아끼우기 때문이다.

## 흐름

```bash
PY="C:/Users/hbox7/AppData/Local/Python/pythoncore-3.14-64/python.exe"

# ① 그림을 뽑고 '아이콘 후보'를 가려낸다 + 좌표로 가까운 글자를 붙인다
"$PY" extract.py <슬라이드.pptx> icons 1
"$PY" iconsheet.py icons          # 번호·문맥이 달린 시트 → 눈으로 무슨 그림인지 확인

# ② 라이브러리에서 후보를 찾아 시트로 본다
"$PY" find.py cand "2:교육훈련" "3:시스템설정" "5:모니터링"

# ③ 고른 것으로 교체(배치 순서 번호 = list 모드 번호)
"$PY" swap.py <원본.pptx> list
"$PY" swap.py <원본.pptx> <결과.pptx> "2=icon_977.png" "5=icon_1181.png"
```

## 무엇으로 바꿀지 정하는 법 — 2단

1. **그림을 본다.** `iconsheet.py` 가 만든 시트를 읽어 무슨 아이콘인지 판단한다.
2. **그림만으론 애매하면 옆 글자를 읽는다.** `extract.py` 가 각 그림의 중심 좌표에서
   가까운 텍스트 3개를 거리와 함께 붙여 준다(0.5~1.0in 이내면 그 항목의 아이콘이 거의 확실).
   - 실제 사례: 노드가 연결된 추상 도형 → 그림만 보면 "네트워크"지만, 옆 글자가
     "안정화 / 장애요소 제거 및 서비스 개선" 이라 **서버 정상 아이콘**을 골랐다.

## 크기·비율 — 자동 보정

- 새 아이콘은 **원본 그림이 캔버스에서 실제로 차지하던 영역(알파 바운딩박스)에 맞춰** 배치한다.
  단순히 캔버스에 꽉 채우면 3D 아이콘의 자체 여백 때문에 **눈에 띄게 작아 보인다**(실측으로 확인).
- 새 아이콘의 투명 여백도 걷어낸 뒤 원본 잉크 영역 중심에 놓는다 → 도형 크기를 안 건드려도
  시각적 크기가 원본과 같고, 가로세로 비율이 달라도 안 찌그러진다.

## 주의

- ⚠️ **도형으로 그린 아이콘은 못 바꾼다.** 이미지가 아니라 벡터 수식이라 `ppt/media/` 에 없다.
  `extract.py` 가 세어 주는 그림 개수와 슬라이드에 보이는 아이콘 수가 다르면 그 차이가 도형이다.
- ⚠️ **같은 이미지가 여러 슬라이드에서 재사용되면 한 번에 다 바뀐다**(부품을 공유하므로).
  한 장만 바꾸려면 `split.py` 로 낱장을 뜬 뒤 그 낱장에서 교체한다.
- ⚠️ **검색어가 빗나갈 수 있다** — '기술지원' 으로 찾으면 티켓·쿠폰이 나온다(태그 매칭).
  `find.py` 시트로 **후보를 눈으로 보고** 고를 것. 한 번에 확정하지 말고 검색어를 바꿔 가며 본다.
- 💡 **스타일 통일**: 라이브러리 자산은 `style_sig`(색감 지문)를 갖고 있다. 한 장표 안에서 톤을
  맞추려면 첫 아이콘을 고른 뒤 그 자산의 세트(`/api/assets/{id}/set`)에서 나머지를 고르면 된다.

# 도형(벡터)으로 그린 아이콘 교체 — 착수보고 55장 실전 (2026-09-10)

이미지가 아니라 **도형 조합**으로 그린 아이콘(원형 배경 + 흰 픽토그램, 또는 픽토그램만)을
라이브러리 자산으로 바꾼다. 위 이미지 교체(`swap.py`)와 달리 도형을 지우고 그 자리에 그림을 넣는다.

## 흐름

```bash
# ① 탐지 — 두 방식을 모두 돌린다(둘 다 놓치는 게 다르다)
"$PY" shape_scan_circle.py  <pptx> <시작번호>   # 원형/사각 배경 + 부품 → groups.json
"$PY" shape_scan_cluster.py <pptx> <시작번호>   # 배경 없는 픽토그램: 가까운 도형 군집 → groups4.json
# ② 판정 — 렌더 위 번호 마킹(mark_groups.py) 또는 자리만 크롭(crop_groups.py) 시트를 눈으로
# ③ 종류→자산 매핑(map.sample.py 복사) 후 교체
"$PY" shapeswap_all.py  <src> <dst>            # groups.json 번호 기준(배경 도형째 제거)
"$PY" shapeswap_bbox.py <src> <dst>            # groups4.json 좌표 기준(배경 카드는 남기고 픽토그램만)
"$PY" icon_enlarge.py   <src> <dst> 0.30        # 얇은 선 자리에 너무 작게 들어간 것 확대
"$PY" nobreak_korean.py <src> <dst> 1           # 한글 어절 잘림 → 어절 앞에 줄바꿈(PowerPoint COM)
"$PY" icon_hashswap.py  <src> <dst> A.png B.png # 이미 넣은 자산 A 를 B 로 전 슬라이드 일괄 교체
```

## 이번에 배운 것

- **한 장표 안 픽토그램은 20여 종이 반복된다**(데이터·검색·문서·폴더·글로벌·링크·계층·체크·타겟·보안…).
  종류마다 자산 하나를 매핑하면 262개를 24종으로 끝내고, 문서 전체 톤이 저절로 맞는다.
- ⚠️ **탐지는 한 방식으로 끝나지 않는다.** 원형 배경 앵커 방식은 배경 없는 픽토그램을 통째로 놓쳤고(37개),
  군집 방식은 **두께 0 인 선 도형을 걸러 조각이 흩어져** 체크·분기 아이콘을 놓쳤다(5개).
  선도 포함하고 군집 거리를 0.17in 으로 넓혀야 잡힌다. 남는 것이 화살표·번호뿐일 때까지 반복.
- ⚠️ **얇은 선 픽토그램 자리는 bbox 가 작아 아이콘이 거의 안 보인다** → 최소 0.30in 로 확대(중심 유지).
- ⚠️ **`eaLnBrk="0"` 을 넣어도 PowerPoint 는 한글 어절 잘림을 막지 않는다**(원본과 줄바꿈 동일 실측).
  `TextRange.Lines(i,1)` 로 실제 그려진 줄을 읽어 어절 앞에 `chr(11)` 을 넣는 것이 유일한 방법.
  `TextFrame2.TextRange.Lines()` 는 문자열을 돌려주니 **TextFrame(1) API** 를 쓸 것.
- ⚠️ 라이브러리 태그 '시계'(icon_1059)는 속도계처럼 보인다 — 시계는 icon_931. 태그가 아니라 시트로 확인.
- 빨간 X(icon_1089)는 부정 의미(부재·불가)에만 1~2곳. 한 슬라이드에 5개 몰리면 톤이 깨진다 → 차단=필터(icon_1209), 이력=시계.
- 마킹 번호를 아이콘 위에 찍으면 **마킹이 아이콘을 가려 숫자 뱃지로 오판**한다 → 판정은 크롭 시트로.
