# 2차 재조립 — GPT Image 시안 → 장표 (BRIEF.md 를 먼저 읽고, 아래가 다른 점)

시안이 없던 16쪽(5·23~29·31~35·37~39)을, 1차 시안(design_ppt)을 참조로 GPT Image 가 새로 만든 시안
`D:/powerPlus/제안서/design_ppt2/sNN.png`(2688×1520, 2000 기준으로 보면 2000×1131)대로 다시 만든다.
원본 장표는 **v0.65**(`청주시_발표자료(제안요약서)_v0.65_가이드.pptx`) — run.py 가 이 쪽들은 자동으로 v0.65 와 design_ppt2 를 쓴다.
`py run.py dump NN out.txt` · `py run.py test NN <스크래치>/sNN` 사용법은 같다.

## 1차와 다른 점
1. **시안 글자는 GPT 가 옮겨 적은 것이라 오타가 있다**(예: 성탄원, 연결→연계 등). 글은 **원래 장표(dump) 문구를 그대로** 쓴다. 시안은 배치·크기·색·그림만 따른다.
   시안의 머리 띠 문구(II./III. 같은 장 번호 포함)는 무시 — 머리말은 레이아웃·기존 글상자를 그대로 둔다.
2. **키메시지**(본문 맨 위 큰 한 줄)는 1차 16쪽과 같은 규칙: 도형 이름 `키메시지`, L0.20 T1.03 W10.43in, 서체 `G마켓 산스 TTF Bold`,
   23pt(가장 긴 줄이 한 줄에 들어가게, 넘치면 0.5pt씩 줄임), 바탕글 남색 `0B2E6B` + 강조 구절 파랑 `2070E8`, 가운데 정렬, 좌우 장식선·띠·알약 없음.
   **시안의 분홍 강조는 쓰지 않는다**(1차에서 파랑으로 확정). 강조 구절은 원래 장표에서 색이 다르던 구절.
   원래 장표의 키메시지 도형은 지우고 새로 쓴다. 두 줄 키메시지(38쪽처럼)는 줄마다 문단, 높이 0.92in.
3. 본문은 키메시지 아래(약 1.62in)부터 **7.02in 안**, 가로 **0.24~10.59in 안**에 둔다(안내선). 쪽 번호 자리(오른쪽 아래) 가리지 않기.
4. **실물은 원래 장표 것을 남긴다**: 증명사진(32쪽), 회사 로고(solideo·VALO — 37·38·39쪽), 인증서·상장 이미지(31·37쪽), 보고서 썸네일(34쪽),
   화면 캡처(27쪽 표 캡처 2~3장, 38쪽 노트북 화면), 25쪽 표. 시안에서 오리지 말고 원래 도형을 지우지 않은 채 자리·크기만 시안에 맞춘다.
   그 밖의 3D 아이콘·인물 일러스트·배지·월계관은 **시안에서 오린다**(`c.crop`, 가장자리 다른 요소 조각 없이, 필요하면 `cut=`).
5. 표(표 도형)가 원래 장표에 있으면 표는 python-pptx 표로 남기거나 다시 그리되, **값·행·열은 원래 장표 그대로**. 머리행 색·줄색만 시안에 맞춘다.
   글이 아주 촘촘한 쪽(24·25·27·28·31·34·35)은 시안 배치를 따르되 글자 7pt 이상·넘침 0 이 우선이다. 무리하면 원래 도형을 살려 색·면·자리만 시안으로 바꿔도 된다.
6. 렌더 비교(`cmp_sNN.png`)는 위=시안, 아래=렌더. 최소 3회 렌더·확인.
