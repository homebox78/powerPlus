## 이 두 작업에서 굳은 규칙

1. **원본 백업을 먼저 만든다**(`.원본백업.pptx`) — 아이콘 오교체는 "원본에 뭐가 있었나" 대조로만 잡힌다.
   실제로 원본 아래화살표를 픽토그램으로 오인해 모니터 아이콘을 넣어 뒀던 것을 이렇게 찾았다.
2. **탐지는 한 방식으로 끝나지 않는다.** 남는 게 화살표·번호뿐일 때까지 방식을 바꿔 반복.
3. **판정은 크롭/컨택트시트로 눈으로.** 태그 이름·검색어는 빗나간다(기술지원→티켓·쿠폰).
4. **일괄 스크립트를 돌린 뒤엔 전 슬라이드 렌더 재검수.** 규칙 하나가 다른 구조의 카드에서
   조용히 사고를 낸다(6차 교훈, 7차에 회귀 8건으로 실증).
5. **정렬 규칙은 이동량 상한(0.12~0.25in)을 같이 둔다.** 상한 없이 적용해 설명이 카드 헤더 띠
   위로 올라간 사고가 있었다.
6. **자동 검수의 위반 목록은 '보정 후보'지 '보정 지시'가 아니다.** 렌더로 확인하고 깨지면 원위치
   (s12 는 audit 오탐, s27 은 규칙 영구 제외).
7. **COM 열거값을 기억으로 쓰지 않는다.** `AutoShapeType=148` 을 round2SameRect 로 추측해 별 모양이
   됐다 — 도형 기하는 XML `prstGeom` 직접 지정이 안전.
8. **용어는 사용자가 보는 UI 라벨 기준으로 해석한다**(알파값 = 투명도).
