# 자산 시트 등록 도구 (2026-09-30)

사용자가 **이미 투명 처리한** 시트 이미지를 낱개로 잘라 powerPlus 에 올릴 때 쓴다.

| 파일 | 하는 일 |
|---|---|
| `alpha_slice.py` | **알파만 보고** 자른다(알파 > 24). 픽셀 색·알파는 바꾸지 않는다. 행 → 열 투영, 작은 조각은 가까운 조각에 합치고 너무 넓은 조각은 안쪽 빈 열에서 다시 가른다. 여백 4px, 축소는 premultiplied(RGBa) LANCZOS |
| `dup_match.py` · `dup_assign.py` | 새 조각과 기존 자산을 32×32 회색 상관으로 짝지음(같은 원 시트 안에서 1:1). 짝은 눈으로 한 번 더 본다 |
| `tag_merge.py` | 비전 태깅 결과 합치기 + 묶음 스타일 태그 앞에 붙이기, NFC·중복 제거, 커버리지 검사 |
| `illust-fix.php` | 서버 일회용 러너(키가드): 중복 덮어쓰기(id·태그 유지, 썸네일·지문 재계산) / 묶음별 등록시각 나누기 / 세트 크기 확인. 실행 후 삭제 |

⚠️ 옛 `slice.py` 의 "옅은 회색 칸 바탕 제거"는 **밝은 불투명 픽셀(얼굴·흰 셔츠·책상)까지 투명하게** 만들었다 — 투명 처리된 원본에는 절대 쓰지 말 것.

세트 = 등록 배치(created_at 30분) + 색감 지문(style_sig). 눈으로 나눈 묶음을 세트로 만들려면 묶음마다 created_at 을 45분씩 띄우고 style_sig 를 묶음 다수값으로 맞춘다.
