# powerPlus 관리자 안내 (관리자용)

자산·카테고리·공지·콘텐츠 요청을 관리하고 사용 통계를 보는 웹 대시보드입니다. 설치 없이 브라우저로 접속합니다.

## 1. 접속 & 로그인
- 주소: **https://hom2box.com/powerPlus/admin/**
- 로그인: **회사 이메일 + 6자리 인증코드(OTP)** — 단, 관리자로 **등록된 계정**만 접근됩니다.
  - 관리자 추가는 개발/운영자가 서버 설정의 `admin_emails` 에 이메일을 넣어줍니다.

## 2. 화면 구성
- **대시보드**: 총 삽입 횟수·전체 자산 수·사용된 자산·총 즐겨찾기(KPI), 인기/즐겨찾기 순위, 카테고리별 분포.
- **자산**: 등록/수정/삭제. 카테고리 필터 + 태그 검색.
- **카테고리**: 추가/수정/삭제(아이콘·사진·일러스트·다이어그램·장표).
- **공지**: 작성/활성화 → 사용자 애드인 우측 상단 알림에 표시.
- **요청**: 사용자가 보낸 콘텐츠 요청 처리(완료/거절).

## 3. 자산 등록 방법
- **이미지 자산**(아이콘/사진/일러스트/다이어그램): 카테고리 선택 → 이미지(PNG·JPG) 업로드 → **국문/영문 키워드** 입력(검색용, 많을수록 좋음) → 저장.
- **장표(ppt)**: 카테고리=장표 선택 →
  - **장표 파일(.ppt/.pptx)** 업로드(필수) + 썸네일 이미지(선택)
  - **장표 유형**: `패키지`(발표장표 전체) / `단일 페이지`
  - 단일이면 **페이지 종류**: 표지·목차·간지·콘텐츠·인사말·Q&A·기타
  - 저장. (사용자가 클릭하면 슬라이드로 삽입됩니다)

## 4. 대량 자산 등록 (개발/운영자 경유)
많은 자산을 한 번에 올릴 때는 자동 파이프라인을 사용합니다(국문25·영문25 키워드 자동 태깅).
- 운영자가 `data/_incoming/<카테고리>/` 에 이미지를 넣고 등록을 실행 → 리사이즈·태깅·썸네일·등록까지 자동.
- 자세한 절차: 개발 문서 `server/bin/ASSET-IMPORT.md`.

## 5. 보안 주의 (운영자 확인 필요)
- 관리자 페이지/DB 도구(phpMyAdmin)는 **인터넷 공개 최소화**(IP 제한 권장).
- 관리자 계정 이메일만 `admin_emails` 에 등록(최소 인원).
- 자세한 인프라 보안 항목은 개발/운영자 체크리스트 참조.
