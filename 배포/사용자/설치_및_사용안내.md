# powerPlus 설치 및 사용 안내 (사용자용)

PowerPoint에서 회사 자산(아이콘·사진·일러스트·다이어그램·장표)을 바로 검색해 슬라이드에 넣는 추가 기능입니다.

## 1. 설치 (1분, 관리자 권한 불필요)
1. **`powerPlus_Setup.exe`** 를 더블클릭합니다.
2. 설치 마법사에서 **다음 → 동의 → 설치** 를 누릅니다. (설치 위치는 그대로 두면 됩니다)
3. "설치가 완료되었습니다" 가 나오면 끝입니다.

> 준비물: Windows 10/11, Microsoft PowerPoint 2019 이상 또는 Microsoft 365, 인터넷 연결, 회사 계정(@solideos.com)

## 2. 실행 위치
PowerPoint 실행 → 상단 **[삽입]** 탭 → **[추가 기능]** → **[개발자 추가 기능]** → **powerPlus** 클릭
→ 오른쪽에 작업창이 열립니다.

## 3. 로그인 (최초 1회)
1. **회사 이메일**(예: `hong@solideos.com`) 입력 → **인증코드 받기**
2. 메일로 받은 **6자리 코드** 입력 → 로그인

> 메일이 안 보이면 **스팸/휴지통**도 확인하세요.

## 4. 사용법
- **검색/카테고리**: 아래 입력창에 키워드를 적거나(예: "화살표", "회의"), 카테고리(아이콘/사진/일러스트/다이어그램/장표)를 골라 탐색합니다.
- **삽입**: 원하는 카드를 **클릭**하면 현재 슬라이드에 들어갑니다. (장표는 슬라이드로 삽입)
- **즐겨찾기(★)·최근**: 자주 쓰는 자산을 모아 보세요.
- **콘텐츠 요청**: 우측 상단 프로필 → "콘텐츠 요청하기" 로 필요한 자료를 관리자에게 요청할 수 있습니다.
- **공지(🔔)**: 새 자산/업데이트 소식이 우측 상단 알림에 표시됩니다.

## 5. 자주 묻는 질문
- **아이콘이 예전 그림으로 보여요** → PowerPoint를 껐다 켜면 새 아이콘으로 갱신됩니다.
- **목록이 안 보여요** → 인터넷 연결을 확인하고 작업창을 새로고침하세요.
- **삭제(제거)** → Windows '앱 및 기능'에서 powerPlus 제거, 또는 설치 마법사 재실행.

문의: 관리자에게 연락 주세요.
